Titled Minecraft Modpack

Installing the Easy Way (But needs some setup):

1. Download the Twitch App and set it up
2. Click on the Mods tab in the Twitch App and click on Minecraft, and click Install
3. If Minecraft says "Not Installed" click on the faded icon and locate minecraft in %appdata%
4. Download this ZIP File: Twitch (Curseforge) Pack
5. In the Minecraft menu, click on Create Custom Profile, then on "import a previously created file". Select the zip file you just installed
6. Whilst waiting for it to install, click on your profile in the top right, then click on Settings and go to the Minecraft tab
7. Scroll down to the bottom of the page and under "Allocated Memory", change the slider to ideally at least 4096MB, up to 6144 if you can afford it
8. Once installed, click play on the modpack and wait for it to load up

Installing the Ever So Slightly Harder and Less Convenient Way:

1. Download Minecraft Forge and run through the installer to install the client
2. Ask me for the link to the manual file
3. Press the windows key, type "%appdata%" and hit enter
4. Click on .minecrft
5. If "mods" and "config" folders exist, delete them (back up if necessary)
6. Open the ZIP file and drag everything inside of it into your .minecraft folder
7. Open the Minecraft Launcher, then click on Installations and select "forge". Under more options, type the following:
- Xms4G -Xmx4G -XX:+UnlockExperimentalVMOptions -XX:+UseG1GC -XX:G1NewSizePercent=20 -XX:G1ReservePercent=20 -XX:MaxGCPauseMillis=50 -XX:G1HeapRegionSize=32M
8. Run Minecraft
